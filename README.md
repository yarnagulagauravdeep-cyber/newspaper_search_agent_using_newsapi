# Newspaper Search Agent

A web application that allows users to search and browse news articles using the NewsAPI.

## Features

- 🔍 **Search News**: Search for articles by keywords
- 📰 **Browse Articles**: View articles in a responsive grid layout
- 🎨 **Modern UI**: Beautiful gradient design with smooth animations
- 🔗 **Direct Links**: Click on any article to read the full story

## Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with gradients and animations
- **JavaScript (ES6+)**: Async/await for API calls
- **NewsAPI**: For fetching real-time news data

## How to Use

1. Open `webpage.html` in your web browser
2. Enter a search query in the search bar
3. Click the "Search" button
4. Browse the articles in the grid
5. Click on any article card to read the full story on the news source's website

## API

This application uses [NewsAPI](https://newsapi.org/) to fetch news articles. The API key is embedded in the code for demonstration purposes.

## Files

- `webpage.html` - Main HTML structure
- `web-page.js` - JavaScript logic for fetching and displaying articles
- `nav.css` - Navigation bar styling
- `main.css` - Main content and card styling
